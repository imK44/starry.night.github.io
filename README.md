# Starry Night

Starry Night is a side-scrolling platformer built with [p5.js](https://p5js.org/) where you guide a runner across a glowing landscape filled with canyons, obstacles, and collectibles. The goal is to reach the end of the level without losing all of your hearts.

### Deployed link - https://starry-night-kmt.vercel.app/

## Running Locally
1. Clone this repository.
2. Start a local HTTP server in the project root and open the site in your browser:
   - **Python**: `python3 -m http.server`
   - **Node.js**: `npx http-server`
3. Navigate to `http://localhost:8000` (or the port reported by your server).
4. Alternatively, host the project on **GitHub Pages** by enabling Pages for this repository.

## Features
- Dynamic side-scrolling terrain under a starry sky.
- Canyons, hurdles, and other obstacles to jump or avoid.
- Collectible hearts representing player lives.
- Background music and sound effects for movement, jumps, and item pickups.
- Animated arrows and particle effects for added feedback.
